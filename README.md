# Value Ledger Lite | Benefits Realization

A benefits realization tracker for following project value and ROI from business case to realized outcomes. Built as an AI-assisted prototype.

**Live demo:** https://nnekaanadu-art.github.io/value-ledger/

## What it does

- **Benefits dashboard:** financial realization, benefits on track and at risk, net financial value, and a planned vs actual chart.
- **Initiatives:** sponsor, owner, status, delivery date, and approved budget for each initiative.
- **Benefits and tracking:** financial and non-financial KPIs with baselines, targets, owners, and measurement methods, plus monthly planned and actual results and program costs.
- **Green, Amber, and Red status:** based on progress toward the planned value, with hover descriptions.
- **Monthly and quarterly views:** quarterly KPIs use sum, average, or latest month.
- **Executive brief:** a one-page leadership summary that can be printed or saved as a PDF.
- **Data export and import:** JSON and CSV export, and JSON import.

## How to use it

Open the live demo link above. No installation is needed. Data is saved in your own browser only.

## Note

All data in this prototype is fictional and for demonstration purposes only. Figures are illustrative and are not audited financial results.
